# Piano Backing Generator ROCK for Ableton Live

**Piano Backing Generator ROCK** is a rock-focused Max for Live MIDI generator for creating expressive piano accompaniment directly inside Ableton Live.

It transforms MIDI chord input into rock-oriented piano backing patterns, including rhythmic chord playing, arpeggios, octave patterns, driving accompaniment, and expressive ballad performances.

The device is designed for use with your preferred piano VST, Kontakt instrument, or other MIDI-compatible sound source.

## Features

- 2,600 presets across 26 rock genres
- BACKING, ARPEGGIO, and HYBRID performance styles
- Rock-oriented rhythmic chord generation
- Left-hand and right-hand accompaniment
- Octave-based and driving piano patterns
- Ballad-style sustained accompaniment
- Adjustable rhythmic accents and performance dynamics
- BACKBEAT control for emphasizing rock rhythms
- MIDI keyboard and MIDI clip input
- Real-time MIDI performance generation
- MIDI recording and piano-roll preview
- MIDI clip writing
- NEW TAKE and APPEND TAKE functions
- MIDI export
- MIDI CC, pitch bend, and aftertouch handling
- Time-signature support
- Single `.amxd` device

## How to Use

1. Add Piano Backing Generator ROCK to a MIDI track in Ableton Live.
2. Place your preferred piano instrument after the device.
3. Select a rock genre and preset.
4. Provide MIDI chord input from a MIDI keyboard or clip.
5. Adjust the accompaniment parameters.
6. Record or generate a piano performance.
7. Write the generated notes into a MIDI clip or export the MIDI data.
8. Edit the resulting MIDI in Ableton Live as needed.

The device generates MIDI data and does not contain its own piano sound engine.

## MIDI CC, Pitch Bend, and Aftertouch

**Important:**

Ableton Live's Max for Live MIDI clip-writing functionality does not automatically preserve all MIDI expression data.

When using MIDI CC, pitch bend, or aftertouch, use the device's **MIDI EXPORT** function to preserve these events.

The WRITE CLIP function is primarily intended for writing generated MIDI notes.

For performances that depend on expression data, MIDI export is recommended.
